# Панель ВАЗ 2105 для Android (OBD-II ELM327)

Цифровая спортивная приборная панель для автомобиля ВАЗ 2105 (Жигули) под Android.

## Возможности
- Чтение параметров ЭБУ через Bluetooth ELM327 (Скорость, Обороты, Температура ОЖ, Температура на впуске, Уровень топлива)
- Автоматический расчет текущей передачи (N, 1, 2, 3, 4, 5) на основе передаточных чисел коробки передач ВАЗ и ГП 4.3
- Режим проекции на лобовое стекло (HUD Mirror Mode) — долгое нажатие на экран
- Поддержка протоколов ISO 9141-2, KWP 5 baud, KWP fast (Январь 5.1/7.2, Bosch M7.9.7, M73, M74)
- Учет максимальной, средней скорости и суточного пробега
- Эффектная анимация стрелок при включении (boot sweep)

## Инструкция по сборке APK

### Способ 1: Сборка в Android Studio на ПК
1. Распакуйте скачанный ZIP архив в отдельную папку.
2. Откройте **Android Studio** и выберите **File -> Open...**, указав распакованную папку.
3. Дождитесь автоматической синхронизации Gradle.
4. Подключите Android-телефон кабелем через режим отладки по USB или выберите пункт меню:
   **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
5. Готовый файл `app-debug.apk` появится в папке `app/build/outputs/apk/debug/` — скопируйте его на телефон и установите!

### Способ 2: Бесплатная онлайн-сборка через GitHub Actions (без ПК и без Android Studio)
1. Создайте бесплатный репозиторий на [GitHub](https://github.com).
2. Загрузите файлы этого проекта в репозиторий.
3. Файл `.github/workflows/build-apk.yml` автоматически запустит сборку APK в облаке!
4. Через 2 минуты во вкладке **Actions** скачайте готовый файл `vaz-dash-2105-debug-apk.zip` с APK внутри прямо на телефон!

### Способ 3: Использование в браузере как PWA (без сборки APK)
- Откройте веб-версию в браузере Google Chrome на телефоне Android.
- Нажмите кнопку «Установить на Android» или выберите в меню Chrome «Добавить на главный экран».
- Приложение будет запускаться на весь экран как нативное Android-приложение, а Chrome поддерживает Web Bluetooth для подключения к адаптерам ELM327!
